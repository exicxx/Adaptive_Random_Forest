# Adaptive_Random_Forest
I developed an adaptive random forest to identify signal-to-noise ratios for the project Feasibility of K-dwarf Asteroseismology for PLATO Satellite Mission Observations. This code integrates with an associate's p-mode signal detection tool, improving signal precision for K-dwarf observational strategies.
Currently, this is the code as it was created. However, I will update this code so it is up to standard with the code I write now.
